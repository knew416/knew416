## About Me

I’m building a career in Identity and Access Management, bringing help desk experience in user access administration, identity lifecycle processes, and access reviews.

My portfolio documents hands-on projects using Microsoft Entra ID, Okta, PowerShell, and Microsoft Graph. I focus on automating access, applying least privilege, and testing that security controls work as intended.

I’m also exploring AI identity security: how to identify non-human identities, assign accountable owners, limit permissions, and trace what an AI agent is authorized to do.
